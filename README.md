# Power-BI-Assignment
Power BI – Sales Data Analysis

 Project Overview

The objective of this assignment is to analyze sales perfomance using Microsoft Power BI.
The project focuses on data cleaning, data transformation, data visualization, and DAX calculations to gain meaningful insights from the sales dataset.


Tools used

Power Query – Data cleaning and transformation.
Microsoft Power BI  – Data analysis and Dashbord creation.
DAX – Calculated tables, calculated columns, and measures.

I've worked on

1. Data Cleaning and Loading
Data cleaning and transformation were performed using Power Query Editor.
Identified and handled missing values.
Removed duplicate rows.
Standardized the OrderDate column into a consistent Date format.
Changed column data types to appropriate formats, such as Text, Whole Number, Decimal Number, and Date.
Used conditional calculations to derive missing values in Unit Price ,Sales,Cost,Profit

2. Data Visualization and Insights
Three visualizations were created using Power BI to analyze the sales dataset.
A. Pie Chart – Order Distribution by Region with Region & OrderID
To showing order distribution across different regions. 

B. Column Chart – Top 5 Trending Products

Visual: Clustered Column Chart 
By Product , OrderID
and done Filter: Top N (Top 5)  for identifying the top most ordered products

C. Line Chart – Profit Trend Over Time
By OrderDate,Profit

3. DAX Calculations
DAX (Data Analysis Expressions) was used to create a calculated table, a calculated column, and a measure.

A. Calculated Table – EastRegionOrders
B. Calculated Column – ProfitCostDifference
C. Calculated Measure – TotalProfit
